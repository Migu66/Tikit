# Tikit - Gestión Inteligente de Tickets

Web app moderna para gestionar tickets de compra digitalmente con OCR, análisis inteligente y visualización de estadísticas.

## 📚 Documentación de la API

La API de Tikit está completamente documentada usando **OpenAPI 3.0 (Swagger)**. Puedes acceder a la documentación interactiva en:

-   **Desarrollo**: [http://localhost:3000/api-docs](http://localhost:3000/api-docs)
-   **Documentación completa**: [docs/API.md](./docs/API.md)

La documentación incluye:

-   ✅ Todos los endpoints con ejemplos
-   ✅ Esquemas de datos (User, Ticket, Stats, Recommendation)
-   ✅ Interfaz interactiva para probar la API
-   ✅ Información de autenticación y códigos de error

## 🚀 Stack Tecnológico

-   **Framework**: Next.js 16 con App Router
-   **Lenguaje**: TypeScript
-   **Estilos**: Tailwind CSS
-   **Base de datos**: PostgreSQL con Prisma
-   **Autenticación**: NextAuth
-   **OCR**: Tesseract.js + OpenAI Vision
-   **Almacenamiento**: Cloudinary
-   **Gráficos**: Recharts
-   **Utilidades**: date-fns
-   **Animaciones**: GSAP
-   **Documentación API**: Swagger/OpenAPI 3.0
